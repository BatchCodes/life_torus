Life Torus Flasher

Flash the Life Torus firmware onto an ESP32-S3-DevKitC-1 from your browser. Version VERSION. Play the simulator · Source code

Before You Start

  1. Use Chrome or Edge on a computer. Other browsers cannot use the serial port.
  2. Connect the "UART" port of the ESP32-S3 board to your computer with a USB data cable.
  3. Click a button below and select the serial port of the board.

If the board does not connect, hold the BOOT button, press and release the RST button, then release BOOT. Then try again.

Game

The Game of Life display. Use this for a finished, tested display.

Bring-Up

Test patterns for a new display. Use this first, to check the wiring and to find the panel layout options. Refer to Display Bring-Up.

Saved Settings

The bring-up firmware saves the panel layout and the intensity on the board. The game uses them. To keep them, do not erase the board when you install the game after the bring-up firmware. Refer to Flashing.
